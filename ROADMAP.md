# Roadmap

Directions we're exploring for GDD after v0.2. These are intentions, not
commitments or dates — priorities follow what real engagements surface.

- **Doctor / self-check.** A command that validates an install and an
  engagement's state, and points at the narrowest fix when something drifts.
- **Progress visibility on long commands.** Clearer in-flight status for the
  research-heavy modules, so a long sizing or customer probe is legible while
  it runs.
- **Continuing the pipeline.** Smoother hand-off from one stage to the next
  (scope → tree → workplan → modules → gates → storyline) without re-driving
  each step by hand.
- **Export.** Deck- and memo-ready output from a finished storyline.
- **First-class headless / CI mode.** Running the workflow unattended against
  a data room, for teams that want it in a pipeline.
- **Smoother multi-deal work.** Better ergonomics when several engagements
  live side by side.
