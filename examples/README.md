# Worked example

A complete GDD engagement, start to finish, so you can see what the tool
produces before running it yourself.

## `kestrel-sound/` — "Project Kestrel"

A full MVP pipeline run — `scope-deal → hypothesis-tree → workplan →
size-market → map-competitors → triangulate → red-team → storyline` — on a
**fictional target in a real market**: "KestrelSoft," a vertical
field-service-management SaaS for US pest-control operators (~$40M ARR band),
under a PE control buyout at ~6× ARR. The client's prior going in: "growing
niche, #2 player, defensible compliance moat."

The target and its financials are invented; the market
(US pest-control field-service software) is real, so the agents did genuine
desk research against verifiable public sources. **This is an illustration of
the workflow, not investment advice.**

### What to read, and what it demonstrates

| File | What it shows |
|---|---|
| `.diligence/ENGAGEMENT.md`, `.diligence/TAXONOMY.md` | The scope and the convention lock set *before* any analysis — segment definitions, currency/time basis, source hierarchy |
| `.diligence/TREE.md`, `.diligence/WORKPLAN.md` | The thesis decomposed into a MECE hypothesis tree, laid across the timeline |
| `.diligence/LEDGER.md`, `.diligence/SOURCES.md` | Every numbered finding with its evidence, confidence, and a traceable source registry |
| `.diligence/modules/market/FINDINGS.md` | The two blind sizing legs — top-down and bottom-up — landing **1.8% apart** on their primary builds |
| `reports/TRIANGULATION.md` | The consistency gate: unit checks, TD/BU reconciliation, MECE audit, citation coverage, sensitivity |
| `reports/REDTEAM.md` | The adversarial pass — including a risk driver **refuted by an enacted federal rescission**, not hand-waved away |
| `reports/STORYLINE.md` | The pyramid-principle synthesis: a governing thought of **"pass at ~6× ARR"** — against the client's optimistic prior — with every support tracing back to the ledger |

The point of the example is the *discipline*, not the verdict: the sizing
protocol refused to average an irreconcilable headline and recorded it at low
confidence with the residual driver named; the red-team steelmanned the
deal-negative findings rather than dismissing them; and the final storyline
disagrees with the client's thesis with a complete claim → finding → source
audit trail behind it. That is what GDD is built to do — enforce consistency
and traceability, not manufacture agreement.
