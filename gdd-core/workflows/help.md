# Workflow: help

Canonical command index. Print grouped; keep it compact.

## Getting started
- `/gdd:help` — this index; `help <command>` for detail
- `/gdd:start` — choose the right first action for this folder
- `/gdd:tour` — read-only walkthrough of the whole workflow

## Scoping (start of engagement)
- `/gdd:scope-deal <target>` — interview → engagement brief + taxonomy
  lock; initializes `.diligence/`
- `/gdd:hypothesis-tree` — thesis → MECE hypothesis tree → module briefs
- `/gdd:workplan` — modules × weeks, dependency-ordered

## Modules (the analytical work)
- `/gdd:size-market [segment]` — independent top-down + bottom-up sizing,
  reconciled
- `/gdd:map-competitors [focus]` — competitive set, positioning, shares

## Gates (before synthesis)
- `/gdd:triangulate` — D1–D8 consistency & traceability checks →
  triangulation report; a FAIL blocks the storyline
- `/gdd:red-team` — strongest case against the thesis; kills go
  CONTESTED

## Synthesis
- `/gdd:storyline` — pyramid-principle storyline from surviving findings

## Continuity
- `/gdd:resume-work` — reload state, summarize, recommend next
- `/gdd:pause-work` — explicit handoff into STATE.md

Startup ladder: help → start → tour → scope-deal → resume-work.

Detail blocks per command: read the command's own file (frontmatter
`description`, `<objective>`, `<process>`) and summarize it — do not
paraphrase from memory.
