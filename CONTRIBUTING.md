# Contributing

Thanks for looking. GDD is built and maintained by [Navis Advisory](https://github.com/Navis-Advisory);
this repository is a source-available mirror of a private working tree, under
Apache-2.0.

## The most useful thing you can do: open an issue

Issues are open and they're the contribution we value most. A good bug report
or a well-argued feature idea moves this further than a patch would — tell us:

- **Bugs** — what you ran, what happened, what you expected, and the runtime
  (Claude Code / Codex / Antigravity) and OS. A minimal repro is gold.
- **Ideas** — the diligence problem you're trying to solve, not just the
  feature. We care about the underlying need.

## Pull requests

This repo is a mirror, and **PR creation is restricted to collaborators** — so
please don't spend effort on an unsolicited PR; it can't be merged here, and a
merged change would be overwritten on the next sync from our private source of
truth. There's no CLA to sign because we don't take outside code through this
mirror. If you've found a fix, describe it in an issue and we'll carry it
in — you'll get the credit in the changelog.

This keeps maintenance boring and predictable, which is deliberate.

## Security

Please don't file security issues in public. See [`SECURITY.md`](SECURITY.md)
for how to report privately.

## Versioning and releases

See [`docs/VERSIONING.md`](docs/VERSIONING.md). In short: semver, a hand-kept
`CHANGELOG.md`, and a single manual publish to npm.
